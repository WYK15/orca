## Orcaw Tauri 1.4.165-wyk.22-tauri.7

基于 `v1.4.165` 维护线，面向 Apple Silicon Mac 的正式 Release，最低支持 macOS 13.5。

### Markdown 滚动与表格

- 修复快速向下滚动时，文档突然跳回顶部的问题。
- 调整编辑器外层布局，避免 WebKit 在替换屏幕外内容时重置滚动位置；保留窄窗口下的目录浮层。
- 修复点击表格单元格、切换表格或重新显示表格时的高度变化和页面跳动。
- 流程图滚出可见区域后保留已生成的图形，返回时直接显示，减少空白和重复渲染。

### 文字选择与复制

- 修复普通文本代码块、行内代码及列表中选中文字时，背景没有明显变化的问题。
- 代码块内的选择高亮限定在实际选中文字上，避免影响边缘、末尾空白和块下方区域。
- 完善符合 Typora 使用习惯的复制行为：完整格式片段保留 Markdown，局部片段按可见文字复制，并提供富文本格式。
- 修复拖动选择链接文字时意外打开链接的问题。

### 验证与清理

- 补充 macOS 原生滚轮回归测试，覆盖编辑器未获焦点时的连续滚动；测试页复用正式编辑器布局。
- Chrome 和 WebKit 完整回归测试通过，实际 App 的滚动修复也已确认。
- 移除排障期间添加的临时滚动日志采集、调用拦截和日志写入接口。
- 自动检查和下载更新保持关闭。

### 安装和升级

下载 `macos-arm64.dmg`，将 **Orcaw Tauri.app** 拖到 Applications 替换旧版；也可使用 ZIP。
升级前完全退出旧版应用。发布安装包经过 Developer ID 签名和 Apple 公证，并附 SHA-256 校验文件。

应用继续使用 `com.wyk15.orcaw.tauri` 数据目录，已有项目、设置和草稿可继续使用。
本次仅提供 macOS ARM64 安装包。
