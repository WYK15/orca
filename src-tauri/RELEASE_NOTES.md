## Orcaw Tauri 1.4.165-wyk.22-tauri.5

基于 `v1.4.165` 维护线，面向 Apple Silicon Mac 的本地开发。
这是正式 Release，最低支持 macOS 13.5。

### 会话切换修复

- 修复从侧栏切换本地项目或工作区时，提示“唤醒临时虚拟机工作区失败”并停留在原会话的问题。
- 本地会话切换不再依赖已移除的云虚拟机功能，无需通过重新拖入项目来绕过此错误。
- 同时修复工作区休眠、恢复及删除流程中残留的虚拟机接口调用。

### 右键菜单精简

- 移除工作区右键菜单中的“移至状态”“标记为已读/未读”和“睡眠”。
- 批量操作及带后代工作区的菜单也不再显示对应入口。

### 保留的日常功能

- 项目置顶、归档、搜索、批量恢复和撤销。
- 图标大小、侧栏与资源管理器字号、列表密度等外观设置。
- 本地项目、Git 工作树、文件编辑、内容搜索、Markdown 预览和持久终端。
- macOS 通知、原生菜单、剪贴板和钥匙串加密凭据。
- Codex 自己的插件和多智能体能力，以及终端中手动执行的 `ssh` 命令不受影响。
- 网页使用 Chrome 打开，未安装 Chrome 时使用系统浏览器。
- 自动检查和下载更新保持关闭。

### 安装和升级

下载 `macos-arm64.dmg`，将 **Orcaw Tauri.app** 拖到 Applications 替换旧版；也可使用 ZIP。
升级前完全退出旧版应用。安装包经过 Developer ID 签名和 Apple 公证，附带 SHA-256 校验文件。

应用继续使用 `com.wyk15.orcaw.tauri` 数据目录，已有 Tauri 项目和常规设置可继续使用。
首次从 Electron Orcaw 迁移时仍可选择一次性导入项目和常规设置，导入前自动备份。
旧版加密凭据和托管账号不导入，相关账号可能需要重新配置。

本次仅提供 macOS ARM64 安装包；Windows、Linux 和 Intel Mac 暂缓。
