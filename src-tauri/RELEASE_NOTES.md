## Orcaw Tauri 1.4.165-wyk.22-tauri.8

基于 `v1.4.165` 维护线，面向 Apple Silicon Mac 的正式 Release，最低支持 macOS 13.5。

### 文件树与 Finder

- 支持在文件树和 Finder 之间拖入、拖出本地文件和文件夹，支持多选。
- 修复拖到 Finder 后文件弹回、无法放下的问题。现在会等待网页拖拽取消完成，再启动系统文件拖拽。
- 拖到 Finder 时复制文件，原文件保持完整；取消拖拽不会复制文件。
- 支持将原生剪贴板中的文件和文件夹粘贴到文件树目录。
- 文件树自动跟随文件创建、删除、重命名刷新，包含文件夹工作区。
- 文件树右键菜单增加刷新入口。

### 验证与清理

- 7 项真实 Finder 拖放测试通过，覆盖 `orca.yaml`、中文及特殊字符文件名、多文件、文件夹和取消操作。
- 补充拖拽启动时序和工作区归属变化的回归测试。
- 移除排障期间添加的临时拖拽日志代码和写入接口。
- 自动检查和下载更新保持关闭。

### 安装和升级

下载 `macos-arm64.dmg`，将 **Orcaw Tauri.app** 拖到 Applications 替换旧版；也可使用 ZIP。
升级前完全退出旧版应用。签名状态见本页顶部说明，安装包附 SHA-256 校验文件。
未签名版本首次启动若被拦截，可在“系统设置 → 隐私与安全性”中选择“仍要打开”。

应用继续使用 `com.wyk15.orcaw.tauri` 数据目录，已有项目、设置和草稿可继续使用。
本次仅提供 macOS ARM64 安装包。
