## Orcaw Tauri 1.4.165-wyk.22-tauri.4

基于 `v1.4.165` 维护线，面向 Apple Silicon Mac 的本地开发。
这是正式 Release，最低支持 macOS 13.5。

### 项目整理

- 项目支持置顶、归档、搜索、批量归档和恢复，以及撤销操作。
- 左侧底部提供固定的归档入口；项目名称右键菜单也可操作。
- 归档保留项目文件、工作区状态和运行中的终端。

### 外观设置

- 在“设置 → 外观 → 界面”调整图标大小（16–24px）、项目与文件面板字号（12–16px）。
- 列表密度支持紧凑、标准和宽松，可恢复默认大小。
- 设置自动保存；连续调整多个控件时会合并保存，避免相互覆盖。

### 功能精简

- 移除自动化定时任务、Orca 插件管理及插件后台进程。
- 移除 Linear/Jira、模拟器入口和首次使用引导。
- 移除 SSH 主机、远程 Orca 服务器、Orca 智能体编排和工作区板。
- 移除试验性功能，包括桌面宠物、智能体动态视图、智能体看板、原生聊天、智能体休眠、终端提醒、新卡片样式和云虚拟机。
- 旧配置无法重新开启上述功能；远程连接和编排接口不再提供，安装包不再包含 SSH relay 资源。
- Codex 自己的插件和多智能体能力，以及终端中手动执行的 `ssh` 命令不受影响。

### 保留的日常功能

- 本地项目、Git 工作树、文件编辑、内容搜索及 Markdown 预览。
- 持久终端、macOS 通知、原生菜单、剪贴板和钥匙串加密凭据。
- 网页使用 Chrome 打开，未安装 Chrome 时使用系统浏览器。
- 自动检查和下载更新保持关闭。

### 安装和升级

下载 `macos-arm64.dmg`，将 **Orcaw Tauri.app** 拖到 Applications 替换旧版；也可使用 ZIP。
升级前完全退出旧版应用。安装包经过 Developer ID 签名和 Apple 公证，附带 SHA-256 校验文件。

应用继续使用 `com.wyk15.orcaw.tauri` 数据目录，已有 Tauri 项目和常规设置可继续使用。
首次从 Electron Orcaw 迁移时仍可选择一次性导入项目和常规设置，导入前自动备份。
旧版加密凭据和托管账号不导入，相关账号可能需要重新配置。

本次仅提供 macOS ARM64 安装包；Windows、Linux 和 Intel Mac 暂缓。
