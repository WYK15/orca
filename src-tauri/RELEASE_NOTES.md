## Orcaw Tauri 1.4.165-wyk.22-tauri.6

基于 `v1.4.165` 维护线，面向 Apple Silicon Mac 的正式 Release，最低支持 macOS 13.5。

### Markdown 编辑器重构

- 即时渲染、源码和阅读模式共用文档状态与撤销记录，切换模式保留编辑位置。
- 编辑直接修改原始 Markdown 的对应范围，保留未编辑部分的文字、空格、实体和换行格式。
- 标题在输入标题内容后渲染；支持行内语法显示、代码围栏补全和斜杠命令。
- 完善有序、无序列表的回车续项、Shift+Enter 换行、退格移除标记和连续编号。
- 修复列表项内换行、插入代码块后继续编号，以及编号位数变化时子内容缩进的问题。
- 表格支持右键增删行列、对齐、拖动排序、区域选择与粘贴，相关编辑可以撤销。
- 修复本地绝对路径图片和工作区外图片的读取，以及图片尺寸过小和 WebKit 布局问题。
- 支持目录、公式、脚注、常见 HTML、独立 HTML 导出与系统打印/PDF。

### 中文终端输入修复

- 修复中文输入后，双引号需要按两次才能出现的问题。
- 兼容 macOS WebKit 先提交标点文本、后发送按键事件的顺序，避免丢失第一次输入或重复发送。
- 补齐当前输入法识别；回归检查覆盖普通终端、Codex 键盘协议及英文引号。

### 功能精简

- 移除浮动工作区按钮、状态栏入口、设置和快捷键；旧配置不会重新启用这些入口。
- 原有浮动工作区文件、草稿和终端记录保留。快捷键配置文件改为使用默认应用打开。
- 普通项目终端、Markdown 编辑、项目归档和已有外观设置继续可用。
- 自动检查和下载更新保持关闭。

### 安装和升级

下载 `macos-arm64.dmg`，将 **Orcaw Tauri.app** 拖到 Applications 替换旧版；也可使用 ZIP。
升级前完全退出旧版应用。发布安装包经过 Developer ID 签名和 Apple 公证，并附 SHA-256 校验文件。

应用继续使用 `com.wyk15.orcaw.tauri` 数据目录，已有 Tauri 项目、设置和草稿可继续使用。
本次仅提供 macOS ARM64 安装包；Windows、Linux 和 Intel Mac 暂缓。
